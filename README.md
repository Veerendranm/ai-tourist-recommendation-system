## 📌 Project Overview

An intelligent travel recommendation system integrated with a conversational AI chatbot to deliver personalized itinerary suggestions based on user preferences, geographical data, and contextual inputs.

Developed as part of the B.E. Final Year Major Project at **Channabasaveshwara Institute of Technology (CIT)** in technical collaboration with **Eunoia Labs, Bangalore**.

---

## ✨ Key Features

* **💬 Conversational AI Interface:** Uses Natural Language Understanding (NLU) to process natural user queries regarding budget, interests, and duration.
* **🎯 Personalized Recommendation Engine:** Dynamic filtering algorithms that match user profiles to curated destinations, activities, and dining options.
* **🗺️ Context-Aware Itinerary Generation:** Evaluates regional tourist spot proximity to design optimized daily schedules.
* **🌐 Interactive Web UI:** Clean, responsive web frontend powered by Flask backend services.

---

## 🏗️ System Architecture

* **User Input & Intent Extraction:** User queries are parsed using NLU to extract key entities (e.g., budget, location preferences, duration).
* **Recommendation Matching:** Algorithms score and filter destination databases based on intent matching and user constraints.
* **Itinerary Synthesis:** Contextual engine structures top recommendations into cohesive day-by-day travel schedules.

---

## 🛠️ Tech Stack & Tools

* **Core Language:** Python
* **Natural Language Processing:** NLTK / spaCy / NLU frameworks
* **Backend Framework:** Flask / REST APIs
* **Frontend:** HTML5, CSS3, JavaScript
* **Data Processing:** Pandas, NumPy

## ⚙️ Quick Start & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Veerendranm/ai-tourist-recommendation-system.git
cd ai-tourist-recommendation-system
```

### 2. Set Up Environment & Dependencies
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Launch Application
```bash
python app.py
```
